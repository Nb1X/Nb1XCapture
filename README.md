# Nb1XCapture
A simple & open source screen recorder app for Android

## Features
- 🔊 Device audio recording
- 📂 Built-in file explorer
- 🍔 Small overlay with hamburger icon

## Build
### 1. Clone the repo
```bash
git clone https://github.com/Nb1X/Nb1XCapture
```
### 2. Build
### Linux
```bash
chmod +x gradlew
./gradlew assembleDebug
```

### Windows
```cmd
.\gradlew.bat assembleDebug
```
